# whatsmeow ecc3917

Проверены [два коммита после 1956f96](https://github.com/tulir/whatsmeow/compare/1956f9683795cfb695f2e5d37ee5818c9961d266...ecc39170bc14e52b26163ced0828af82df84bf3e).
Зависимость переведена на `v0.0.0-20261113220833-ecc39170bc14`.

- Keepalive заранее получает тот же request ID и сохраняет его для исключения
  ping/pong из debug-журнала. Сетевой формат, версия веб-клиента и вход не
  менялись. Наш warnLog уже отключает debug, но сохраняется актуальная
  реализация библиотеки.
- Новое `events.FBCallEvent` описывает начало, завершение и пропуск звонка
  Messenger. Наш подключённый профиль WhatsApp не использует Messenger;
  это не новая доступная ему возможность и отдельный MCP-инструмент здесь
  не нужен. Схемы protobuf и методы чтения/отправки сообщений не менялись.

Проверка пути keepalive.go в слежении — сигнал для разбора исходников,
а не доказательство смены протокола входа. Ввод через worker-пакет и
`scripts/build.ps1`; повторная сборка или новый вход на ноутбуке не нужны.
