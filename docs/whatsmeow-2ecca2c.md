# whatsmeow 2ecca2c

Обновление с `ecc39170bc14e52b26163ced0828af82df84bf3e` до
`2ecca2c913b933525d800f8084cb0ee31c56c0bb`:
[сравнение upstream](https://github.com/tulir/whatsmeow/compare/ecc39170bc14e52b26163ced0828af82df84bf3e...2ecca2c913b933525d800f8084cb0ee31c56c0bb).
Go-модуль: `v0.0.0-20261116124925-2ecca2c913b9`.

## Совместимость

- Версия веб-клиента меняется с `2.3000.1052556849` на
  `2.3000.1054751086`; обновлены protobuf-схемы.
- Проверка интервала unified session сериализована mutex, а групповый кэш
  клонируется перед изменением, включая срезы участников и администраторов.
- Отложенный `stream:error` обрабатывается и после закрытия соединения.
- Stanza `status` проходит через общий обработчик сообщений;
  `MessageInfo.IsNewsletterStatus` заменён на `StanzaTag`.
  Наш клиент не использует удалённое поле или изменённые методы
  `DangerousInternalClient`.
- `go get` обновил требуемые транзитивные зависимости, включая libsignal,
  util и golang.org/x/*. Минимальная версия Go в модуле осталась 1.26.0;
  рекомендация toolchain в зависимости не меняет настройку toolchain проекта.

WhatsApp по-прежнему обслуживается единственным клиентом службы профиля:
устройство, локальная история, фильтрация журнала и запрет отправлять
прочтения/присутствие сохраняются. В этих шести коммитах upstream нет
изменения SQL-схемы устройства или команды повторного входа.

## Что получает агент

Новый `InstantVideoMessage` включён в существующий путь видеовложений:
подпись, цитата, длительность, размер и превью сохраняются; скачивание
использует исходный protobuf VideoMessage. Обычное видео и GIF сохраняют
своё поведение, PTV остаётся `video_note`. Сама схема нового поля не
доказывает круглую форму видео, поэтому оно показывается как `video`.
Новых инструментов для этого не требуется.

Добавлен синтетический тест Parse → protobuf → MediaInfo для нового и
прежних контейнеров видео. Он не открывает клиент, файлы профиля или сеть.

Другие изменения схемы включают `PaymentDetailsMessage`, технические
VpcRequestMessage, формы вступления в группу, дополнительные поля опросов,
приглашений на события, ключей и AI/Messenger. Наличие protobuf-типа само
по себе не добавляет готовой клиентской операции. Отдельного представления
платёжных деталей и операций форм/платежей в MCP пока нет; отправка денег
из этого обновления не следует. Обычные сообщения и медиа продолжают идти
через существующие инструменты.

## Проверка выпуска

Нужны независимое ревью, полный штатный worker test/vet/build, возврат
манифеста и шести файлов через wk get, проверка новых/резервных хешей и
ввод через scripts/build.ps1. Живая проверка ограничена разрешённым
`whatsapp/ya-zametki-sebe`: чтение и тестовый черновик. Второе соединение,
повторный вход, подписки и другие чаты для проверки не используются.
