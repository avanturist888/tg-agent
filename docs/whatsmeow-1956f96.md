# whatsmeow: исправления синхронизации от 13 ноября 2026

Обновление с `c88388f983b4` до `1956f9683795`:
[три коммита upstream](https://github.com/tulir/whatsmeow/compare/c88388f983b4bc43dfd0bcc2b46969fcde82d61f...1956f9683795cfb695f2e5d37ee5818c9961d266).

- Повторно присланный ключ app-state с прежним ID и другими данными больше
  не заменяет уже сохранённый непустой ключ. Замена нарушала проверку MAC
  ранее зашифрованного состояния; это причина обновить работающий клиент.
  Исправление предотвращает новые замены, но не восстанавливает уже
  повреждённое состояние.
- Ошибки проверки MAC снимка и patch содержат ID использованного ключа
  для диагностики. Сам ключ в эти сообщения не добавлен; журнал остаётся
  за существующим `internal/wac/warnLog`.
- `Logout` поддерживает также Messenger-устройства. Наш профиль использует
  WhatsApp, Messenger не подключён; отдельного инструмента для агентов
  из этого изменения не следует.

Сравнение upstream меняет только `message.go`, `client.go` и
`appstate/decode.go`. `store/clientpayload.go`, схема protobuf, типы сообщений
и событий не менялись. Новых возможностей чтения или отправки для MCP нет.
Устройство, файлы сессии, вход владельца и единственное соединение службы
остаются за существующим `internal/wac`.

`scripts/build.ps1` устанавливает готовый пакет worker и не содержит версии
whatsmeow. Обновлённая зависимость берётся из `go.mod`; повторная сборка
на ноутбуке не требуется. Проверка и ввод следуют
[порядку выпуска](release-worker.md); до их завершения изменение исходников
не означает обновление работающей службы.
